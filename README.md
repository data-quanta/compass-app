# Compass — legal pages

Public hosting for the two pages Apple requires for the **Compass** iOS app:

- [Privacy Policy](https://data-quanta.github.io/compass-app/privacy.html)
- [Support](https://data-quanta.github.io/compass-app/support.html)

This repo is public **only** because Apple's reviewers and the app's users must be able to
open these URLs without signing in. It contains nothing else — no application source.

Canonical source lives in the private application repo under `mobile/legal/`.
To update: edit there, then copy the changed file here and push.
